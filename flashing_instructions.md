# Sailfish OS Flashing Guide: Lenovo Karatep (aarch64)

**WARNING:** Flashing operating systems manipulates low-level partitions. One incorrect step or flashing an incompatible base can hard-brick your device. Follow these instructions precisely.

## Prerequisite: The Android Base
Sailfish OS ports are essentially a "Hardware Abstraction Layer" (HAL) placed on top of an existing Android system's vendor binaries and firmware blobs. 
* **Base Required:** Your `karatep` build was compiled against the **LineageOS 18.1 (Android 11)** hybris base.
* **Critical Check:** Your device **must** be running a fully functional installation of LineageOS 18.1 before flashing this zip. If you are on stock Lenovo firmware, Android 10, or Android 12+, Sailfish OS will either fail to boot (kernel panic) or suffer from severe hardware failure (no Wi-Fi, RIL, or audio).

## 1. Locate the Flashable ZIP
The `mic` image creator is currently outputting a flashable recovery ZIP to your build directory. 
Once `mic` completes, you will find a file named something like `SailfishOS-karatep-5.1.0.11-*.zip` in:
`/opencloud/hadk/SailfishOScommunity-release-5.1.0.11-karatep/`

## 2. Boot into Recovery (TWRP / Lineage Recovery)
Your device is currently detected over USB. Reboot it into your custom recovery.
Run this command from your host terminal:
```bash
adb reboot recovery
```

## 3. Wipe User Data (Required)
Sailfish OS needs a clean `/data` partition to unpack its rootfs.
1. In your custom recovery menu, navigate to **Wipe**.
2. Perform a standard **Factory Reset** (Wipes Data, Cache, and Dalvik).
   * *Note: Do NOT wipe the `System` or `Vendor` partitions. Sailfish OS needs the Android vendor partition intact!*

## 4. Flash the Sailfish OS Zip
You will use `adb sideload` to stream the ZIP file directly to the device.
1. On the device recovery menu, go to **Advanced > ADB Sideload**.
2. Swipe to start the sideload listener.
3. On your host terminal, run:
```bash
adb sideload /opencloud/hadk/SailfishOScommunity-release-5.1.0.11-karatep/SailfishOS-karatep-5.1.0.11-*.zip
```
*(Replace `*` with the exact filename generated by `mic`).*

### What the ZIP does:
* Flashes `hybris-boot.img` directly to the `boot` partition (replacing the Android kernel/initramfs with the Sailfish one).
* Unpacks the massive `rootfs.tar.bz2` directly into your `/data` partition (typically into `/data/.stowaways/sailfishos`).

## 5. Alternative Flashing Method (If TWRP fails)
If TWRP fails to sideload or unpack the ZIP (e.g., due to memory constraints), you can flash manually using the `hybris-recovery` / telnet method and a local web server:

1. **Extract the ZIP on your Host:**
   Extract `hybris-boot.img` and `sailfishos-karatep-release-5.1.0.11.tar.bz2` from the generated ZIP file into a folder on your host machine.

2. **Start a Local Web Server:**
   In the folder where you extracted the files, start a Python HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
   *(Your host IP on the USB network will be `192.168.2.14`)*

3. **Boot into the Sailfish Initramfs:**
   Flash `hybris-boot.img` via fastboot, or boot it directly:
   ```bash
   fastboot boot hybris-boot.img
   ```
   Since the rootfs isn't installed yet, the bootloader will drop into the `mer` debug shell.

4. **Connect via Telnet:**
   Connect the USB cable. Once the network interface initializes, connect via telnet:
   ```bash
   telnet 192.168.2.15 2323
   ```

5. **Download and Unpack the Rootfs:**
   Inside the telnet shell, prepare the `/data` partition, download the tarball, and extract it:
   ```bash
   # Mount the data partition (adjust block device if necessary)
   mkdir -p /mnt/data
   mount /dev/mapper/userdata /mnt/data
   
   # Create stowaways directory
   mkdir -p /mnt/data/.stowaways/sailfishos
   cd /mnt/data/.stowaways/sailfishos
   
   # Download the rootfs from your host
   wget http://192.168.2.14:8000/sailfishos-karatep-release-5.1.0.11.tar.bz2
   
   # Extract the rootfs (this takes time)
   tar -xjf sailfishos-karatep-release-5.1.0.11.tar.bz2
   
   # Cleanup
   rm sailfishos-karatep-release-5.1.0.11.tar.bz2
   ```

6. **Reboot:**
   Reboot the device. It should now successfully boot into the Sailfish OS UI.

## 6. Boot & Initial Verification
1. Once flashing is done, select **Reboot System**.
2. The device will show the Lenovo boot logo, followed by the Sailfish OS logo. 
3. **First Boot Patience:** The first boot takes significantly longer (up to 5-10 minutes) as systemd services initialize and the filesystem expands.

### Telnet / SSH Debugging (If it bootloops)
If the device doesn't reach the UI, it will expose an emergency USB network interface (RNDIS).
1. Connect the USB cable.
2. Ensure your host machine gets an IP address on the new `usb0` (or similar) network interface.
3. You can connect via `telnet 192.168.2.15 2323` or `ssh nemo@192.168.2.15` to access the journal logs (`journalctl -xe`) and debug why the UI (`lipstick`) or hardware services (`vndservicemanager`) are failing.
